What Evolua includes

Core capabilities already implemented in the current V1.

📍

Run tracking

GPS route, distance, pace and elapsed time with field-tested outdoor activity tracking.

🗂️

History & persistence

Completed activities are stored so runners can revisit their routes and workout history.

📴

Offline workout flow

Running sessions can continue without an active internet connection.

👥

Community

User profiles, following and activity visibility create a social running experience.

☁️

Firebase backend

Authentication, cloud-backed user data and app services are integrated with Firebase.

✨

AI coaching

An AI-powered coaching experience supports motivation and the runner journey.
